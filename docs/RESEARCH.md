## Top 10 Pain Points (all competitors)
1. Ad overload — popups, pop-unders, redirect ads on mobile
2. Slow on 2G/3G — heavy HTML + ad scripts
3. Misleading/duplicate info — stale results, cloned content
4. Pushy monetization — sales calls, WhatsApp spam, auto-renewal
5. Broken/expired links to official portals
6. Fake "official" branding (sarkariexam clones sarkariresult name)
7. No structured dashboard — endless link lists
8. Poor notification reliability
9. No exam personalization
10. Cluttered dated UI, poor accessibility

## What official portals do (that we should copy)
- Authority/trust: .gov.in source links, official PDFs, posted dates
- Direct links, no interstitial ads
- Structured dated feeds ("Posted on <date>")
- Grievance/FAQ channel
- Multilingual + archive permanence

## 5 Differentiators NO competitor has
1. **Last-date countdown + "closing soon" banners** ✅ DONE (countdown-tag)
2. **Verified-source badge** with date-checked stamp
3. **State-wise + board filter** with saved preferences
4. **Visual exam calendar** (annual, interactive) ✅ DONE (exam-calendar page)
5. **Dark mode + PWA + Telegram/WhatsApp push** ✅ DONE (dark mode)
